Render a self-contained HTML mockup and open it in the user's browser — the visual companion for design mode.

Use this ONLY in design mode, and ONLY for questions where seeing beats reading: UI layouts, side-by-side visual options, wireframes, or diagrams. For conceptual, trade-off, or scope questions, ask in the terminal instead. Offer the visual companion once (in its own message) before using it, and respect the user's choice.

- `html`: a complete, self-contained HTML document. Inline all CSS; do not reference external assets, scripts, or network resources.
- `title`: a short title used for the generated file name.

The mockup is written next to the current design file and opened in the default browser. If the host has no browser, the tool reports the file path instead of failing — fall back to describing the mockup in text.
