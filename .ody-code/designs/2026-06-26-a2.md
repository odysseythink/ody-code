## Algorithms

### A1 — Binary path resolution

```
function resolveBinaryPath(env: NodeJS.ProcessEnv): string
  if env.ODY_HOST_BINARY_PATH is non-empty
    return env.ODY_HOST_BINARY_PATH
  // Derive repo root from import.meta.url of this test file:
  // packages/node-sdk/test/rust-host-connect.test.ts -> ../../../rust-ody/target/release/ody-host
  candidate = fileURLToPath(new URL('../../../rust-ody/target/release/ody-host', import.meta.url))
  if fs.existsSync(candidate)
    return candidate
  throw new Error(
    `ody-host binary not found at ${candidate}. ` +
    `Build with "pnpm run build:host" or set ODY_HOST_BINARY_PATH.`
  )
```

### A2 — Shared test harness `withRustHost`

```
async function withRustHost<T>(
  options: WithRustHostOptions,
  testFn: (fixture: HostFixture) => Promise<T>
): Promise<T>
  homeDir = await mkdtemp(join(tmpdir(), 'ody-rust-host-'))
  transport = typeof options.transport === 'function'
    ? options.transport(homeDir)
    : options.transport
  client = await SDKRpcClient.connect({
    transport,
    binaryPath: options.binaryPath ?? resolveBinaryPath(process.env),
    homeDir,
  })
  try
    result = await testFn({ client, homeDir })
    return result
  finally
    await client.close?.()
    await rm(homeDir, { recursive: true, force: true })
```

### A3 — Fixed TCP port selection with retry

```
function isAddrInUse(err: Error): boolean
  message = err.message.toLowerCase()
  return message.includes('eaddrinuse')
      || message.includes('address already in use')
      || message.includes('os error 48')
      || message.includes('os error 98')

async function bindTcpHost(testFn: (host: string, port: number) => Promise<void>): Promise<void>
  basePort = 19090
  maxAttempts = 10
  lastErr = undefined
  for offset from 0 to maxAttempts - 1
    port = basePort + offset
    try
      await withRustHost(
        { transport: { host: '127.0.0.1', port, spawn: true } },
        (fixture) => testFn('127.0.0.1', port)
      )
      return
    catch err
      lastErr = err
      if isAddrInUse(err) and offset < maxAttempts - 1
        continue
      throw err
  throw lastErr ?? new Error('bindTcpHost exhausted all ports')
```

### A5 — Test assertion pattern for session lifecycle

```
async function assertSessionLifecycle(client: SDKRpcClient, homeDir: string, fixedId?: string)
  input = { workDir: homeDir, id: fixedId }
  session = await client.createSession(input)
  assert(typeof session.id === 'string')
  if fixedId is defined
    assert(session.id === fixedId)
  sessions = await client.listSessions({ workDir: homeDir })
  assert(sessions.some(s => s.id === session.id))
```

## Error Handling & Degradation

| Error class | Immediate handling | Degradation path | Recovery condition |
|---|---|---|---|
| Binary not found | `resolveBinaryPath` throws before spawn | Test fails fast with actionable message | Build `ody-host` or set `ODY_HOST_BINARY_PATH` [C:USER] |
| Spawn failure (ENOENT/EACCES) | `spawnHost` rejects via `proc.once('error')` added in A1 | Test fails with binary path + args in message | Fix binary path or permissions [C:INFERRED] |
| Host exits before ready | `waitForReadyMessage` rejects with exit code/signal | Test fails; CI uploads stderr logs | Investigate Rust panic or CLI mismatch [C:INFERRED] |
| TCP EADDRINUSE | `bindTcpHost` retries next port up to maxAttempts | If exhausted, throw original error | Increase port range or switch to port 0 strategy [C:USER] |
| Duplicate session id | Rust returns error; TS test asserts rejection | N/A | Use unique ids per test [C:USER] |
| Client close leaves zombie process | `finally` block calls `client.close()` then `rm(homeDir)` | If `close()` hangs, attach `setTimeout` + `proc.kill('SIGKILL')` | Process exits; OS reaps zombie [C:INFERRED] |
| UDS socket path too long | Test fails with `ENAMETOOLONG` | Shorten tmpDir suffix or use abstract socket | Path length < platform limit [C:INFERRED] |

## Self-Review

### High-stakes decisions & adversarial inputs

#### D1 — Rust `create_session` id extraction

Rule: `id` is taken from `payload.get("id").and_then(|v| v.as_str()).filter(|s| !s.is_empty())`. If present and non-empty, call `create_with_id`; otherwise generate UUID v7.

| Input `id` | Expected behavior |
|---|---|
| `"custom-1"` | Session id = `"custom-1"` |
| `""` (empty string) | Treated as absent; UUID generated |
| `null` / missing field | Treated as absent; UUID generated |
| `"   "` (whitespace only) | Treated as valid id; session id = `"   "` [C:INFERRED] |

No code change required; whitespace-only id is an edge case the implementer may choose to trim, but A2 does not require it.

#### D2 — TCP `isAddrInUse` retry predicate

Verified with ephemeral Node script (6 cases, all PASS). See `/tmp/check-addr.mjs` output.

| Input error message | Expected retry? |
|---|---|
| `"EADDRINUSE: address already in use :::19090"` | Yes |
| `"cannot bind tcp socket 127.0.0.1:19090: Address already in use (os error 48)"` | Yes |
| `"cannot bind tcp socket 127.0.0.1:19090: Permission denied (os error 13)"` | No |
| `"unexpected argument 'serve' found"` | No |

#### D3 — Binary path resolution

Rule: `ODY_HOST_BINARY_PATH` overrides; otherwise derive from `import.meta.url` (`../../../rust-ody/target/release/ody-host`); if missing, throw.

| Scenario | Expected path |
|---|---|
| `ODY_HOST_BINARY_PATH=/opt/ody-host` | `/opt/ody-host` |
| Test file at `packages/node-sdk/test/rust-host-connect.test.ts`, binary built | `rust-ody/target/release/ody-host` relative to repo root |
| Binary not built | Throws with build hint |

### Four-lens sweep

**Security**
- No API keys or tokens in test data. [C:USER]
- `homeDir` is a random temp directory; no user `~/.ody` mutation. [C:USER]
- Deterministic test ids (`stdio-session-id`, etc.) are not PII.
- `isAddrInUse` only inspects error message strings; no code execution.

**Test**
- Must-pass: fixed-id creation, auto-id creation, stdio/uds/tcp transports, listSessions contains created session, process exits cleanly. [C:USER]
- Must-reject: binary not found (fail fast), duplicate id (Rust unit test), non-EADDRINUSE spawn error (no retry). [C:USER] [C:INFERRED]
- No assertion contradicts its own rule (e.g., UUID length check matches UUID v7 length).

**Ops**
- Each test case spawns a fresh `ody-host` with isolated `homeDir`; parallel test files cannot collide. [C:INFERRED]
- Tests within the file run serially (Vitest default for tests in one file), avoiding TCP port races. [C:INFERRED]
- TCP retry range is 10 ports; if exhausted, the original error is thrown. [C:USER]
- `finally` cleanup deletes `homeDir` and `client.close()` kills the process. [C:INFERRED]

**Integration**
- `SDKRpcClient.connect`, `createSession`, `listSessions`, `closeSession`, and dynamic `close()` all exist in `packages/node-sdk/src/rpc.ts`. [C:INFERRED]
- Rust `serve` subcommand and `SessionManager::create_with_id` exist. [C:INFERRED]
- Target path is exactly the user-named file `packages/node-sdk/test/rust-host-connect.test.ts`. [C:USER]

**Scope**
- This remains one coherent subsystem: a cross-language RPC test with supporting Rust change and CI/ADR updates. No decomposition needed.
