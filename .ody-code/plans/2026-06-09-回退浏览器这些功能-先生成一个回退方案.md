# 回退浏览器功能 — 实施计划

**Goal:** 完全回退 `packages/agent-core` 中所有原生浏览器工具（Puppeteer）及其相关的配置、权限、MCP 注册、Session 生命周期变更，恢复代码至 commit `ace5ba1` 的等价状态（保留非浏览器提交 `d1ccdbc` 和 `1e2d514` 以及 `chrome-devtools.ts` 的 `--autoConnect` 预置变更）。

**Tech Stack:** TypeScript, pnpm, vitest, git

> For executing workers: implement this plan task-by-task (prefer a fresh subagent/Task per task — a clean context per task avoids single-session degradation). Steps use - [ ] checkboxes for tracking.
