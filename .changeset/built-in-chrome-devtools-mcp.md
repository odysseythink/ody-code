Add built-in Chrome DevTools MCP server for browser automation. The server is automatically available in new sessions, connects to a local Chrome instance via the remote debugging port (default 9222), and can be disabled through the `[browser]` config section. Session tool calls are traced to the session directory with sensitive arguments redacted.
